# ケプストラム分析ライブラリ 要件 (v1)

## 位置づけ
他アプリケーションに組み込める DSP ライブラリ．Python / NumPy のみに依存し，
結果が引数だけで決まる純関数＋不変データクラスで構成する．

**目的**：音声を，スペクトル包絡を表す**低ケフレンシ成分**と，微細構造（ピッチによる倍音の山谷など）を表す**高ケフレンシ成分**に分離する．
数学的な定義は [definitions.md](definitions.md) にまとめる．

### 提供するもの
- **実ケプストラム**（振幅スペクトルから計算する実・パワーケプストラム）の計算
- ケプストグラム（短時間ケプストラム）の計算
- スペクトル入力（複素・振幅・パワー，片側・両側）
- リフタリングと，低・高ケフレンシ成分への分離
- ケプストグラムからの時間信号の再構成
- ケフレンシの単位変換（kHz⁻¹・周期 [Hz]・秒）
- 入力の検査（警告とエラー）
- `examples/`：音声を低・高ケフレンシ成分に分ける様子を示すサンプル（描画，WAV の入出力，音声合成を含む）

## 1. 入力
| 入力 | 仕様 |
|---|---|
| 時間信号 | 1次元 `[N]` または多チャネル `[ch, N]`．多チャネルはチャネル平均でモノラル化 |
| スペクトル | `Spectrum(data, fs, n_fft, kind, sided)` |

- `kind`: `complex` / `amplitude` / `power`（power は √ で振幅へ変換．単位は線形）
- `sided`: `one`（`n_fft//2+1` 点）/ `two`（`n_fft` 点）．内部では両側複素スペクトルへ正規化
- ケプストラムの計算には**振幅**を使う．複素スペクトルを入力すると，その振幅を使う（`kind` による結果の違いはない）
- 振幅・パワー入力の `data` は |X| としてそのまま使う（片側の 2 倍などの補正なし）

## 2. ケプストラム
- 種類: `real` = IFFT(ln|X|) / `power` = |IFFT(ln|X|²)|²
- 実ケプストラムは実かつ偶対称（`c[n] == c[-n]`）
- **平均ケプストラム**: 全区間を1回の FFT で計算（方式 (a)）．`cepstrum()`
- **ケプストグラム**: 短時間フレームごとに計算し `[quefrency, frame]` で返す．`cepstrogram()`
  - フレーム長・シフト・窓（hann/hamming/rect/配列）・FFT 長を指定可
  - 時刻軸 `times`，ケフレンシ軸 `quefrency`（秒）を持つ
- 対数の下限は相対値 `eps`（最大値比）
- **dB フラグ `db`**（`cepstrum` / `cepstrogram` / `analyze_*`，既定 `False`）：逆 FFT の前の対数スペクトルを自然対数 ln|X| から
  20·log10|X| [dB] に切り替える．実ケプストラムは 20/ln(10) 倍（FFT すると dB スペクトルになる）．パワーケプストラムは
  dB 基準の |IFFT(20·log10|X|)|²．`Cepstrum.db` / `Cepstrogram.db` に保持し，`log_spectrum()`（常に dB で返す）と再構成
  は単位を自動判別する．リフタは単位に依存しない

## 2.5 入力の検査
- **警告**（`UserWarning` の派生，`warnings` で抑制・例外化可）：
  - `SilenceWarning`：無音（全ゼロ）または定数の信号，全ゼロのスペクトル
  - `ClippingWarning`：信号自身の最大値または最小値に 3 サンプル以上連続して張り付く（スケールに依存しない．多チャネルはチャネルごと．
    判定の対象は 0 以外の極値で，ゼロへの張り付きはゼロ埋めと区別できないため判定しない）
- **エラー**（`ValueError`）：NaN・inf，複素の時間信号，空の信号，形状が `[N]` / `[ch, N]` 以外，`fs` が有限の正数以外，
  `hop` が `1..frame_len` の範囲外，`frame_len < 1`，スペクトルの NaN・inf，負または非有限のリフタのカットオフ・`period_hz <= 0`
- ケプストグラムの検査は信号全体に対して 1 回（フレーム単位の無音は正常として通す）

## 3. リフタリングと再構成
- リフタ: 符号付きケフレンシ(秒)→重み の関数，または長さ `n_fft` の配列．`lowpass / highpass / bandpass / notch` を提供
- `apply_lifter` は平均ケプストラム・ケプストグラムの両方に適用可能
- **時間信号への再構成はケプストグラム**（`reconstruct_cepstrogram` / `Decomposition.reconstruct`）
- 再構成の方式（元の位相を使う）：
  1. 時間信号から複素スペクトログラム X を **1 回だけ計算**し，`Cepstrogram` に保持する（`store_spectrogram`，既定 True）．
     元のパワースペクトログラムは |X|²
  2. リフタ後のケプストグラムを FFT して exp を取り，リフタ後の振幅 |X^ℓ| を得る（パワー |X^ℓ|²）
  3. ゲイン **G = |X^ℓ| / |X| = √(|X^ℓ|² / |X|²)**（振幅比．パワー比 |X^ℓ|²/|X|² を振幅にかけると補正が dB で 2 倍になるため，振幅比を採用）
  4. Y = X · G を逆 FFT し，`frame_len` で切り，**合成窓**（分析窓と同じ）をかけて重畳加算，Σ窓² で正規化
  - リフタなしなら G = 1 で，元の信号に戻る．`|X|` が下限（フレームのピーク × 1e-12）未満の周波数では下限を使い，
    無音フレームは 0 のまま
  - `Decomposition.reconstruct`: `"full"` = 元の信号，`"low"` = 低域の振幅 + 元の位相，`"high"` = `full − low`（時間領域の差）
  - 位相は元のまま，リフタで変わるのは振幅．`low` 信号のフレームごとの振幅は，包絡へ近づく
  - `low + high == full` は，ケプストラム（対数スペクトル）の領域と時間領域の両方で成り立つ
  - 再構成に使うのは，`kind="real"` で作り，複素スペクトログラムを保持したケプストグラム
  - 式の詳細は [definitions.md](definitions.md) の 9 節

## 3.5 ケフレンシの単位
ケフレンシ q は周波数の双対量で，[s] = [Hz⁻¹]．ケプストラム係数 c は，対数スペクトル上の cos(2π·q·f) の「波」の大きさであり，
**q 個/Hz の波（= 周期 1/q Hz の波）** を表す．

| q | kHz⁻¹（= 山/kHz） | 波の周期 |
|---|---|---|
| 1 ms | 1 | 1000 Hz（フォルマント間隔） |
| 8 ms | 8 | 125 Hz（f0=125 Hz の倍音間隔） |

- 内部の数値・`Cepstrum.quefrency` は秒（= Hz⁻¹）で保持する
- 表示・軸の主単位は **kHz⁻¹**（SI 接頭辞により 1 kHz⁻¹ = 1 ms で，数値は ms と同じ）．「1 kHz あたりのスペクトルの山の数」と読む
- 周期 [Hz]（= 1/q）は補助軸として併記する
- cycle 単位（2π 倍の rad/Hz との違いに注意）
- q=0 の c[0] は全体レベル（ゲイン）で，周期は ∞．表現できる最大のケフレンシは q = N/(2fs)（周期 2Δf）
- API: `quefrency_axis(ceps, unit)`，unit は `"Hz^-1"`(=`"s"`) / `"kHz^-1"`(=`"ms"`) / `"period_Hz"`．`from_seconds` / `to_seconds` で変換
  （軸ラベルなど描画向けの部品は examples 側にある）
- リフタは秒の位置引数のほか，`khz_inv=` / `period_hz=` で指定可（例：`lowpass(period_hz=300)`＝300 Hz より幅広い波を残す，
  `bandpass(period_hz=(167, 100))`，`notch(period_hz=125, width_khz_inv=2)`）．指定の形式は 1 つ

## 3.6 分析別の高水準 API（low / high 分割）
分析ごとに1ファイル・1関数．入力は時間信号（多チャネルは平均）または `Spectrum`，戻り値は共通の `Decomposition`．

| ファイル | 関数 | 備考 |
|---|---|---|
| `real_cepstrum.py` | `analyze_real` | 実ケプストラム |
| `power_cepstrum.py` | `analyze_power` | パワーケプストラム |
| `cepstrogram_analysis.py` | `analyze_cepstrogram` | `kind` = real/power，全フレームに同じリフタを適用．`reconstruct` を持つ |

- リフタ指定：`lifter=`（関数または配列），または低域通過のカットオフを `cutoff`[s=Hz⁻¹] / `khz_inv` / `period_hz` のいずれか1つで指定．
  未指定なら分割なし（`low`=`full`，`high`=0）
- `Decomposition.full / low / high`：`low` = リフタ通過（スペクトル包絡，c[0] を含む），`high` = `full - low`（微細構造）．
  `low + high == full` が厳密に成り立つ
- `log_spectrum(part)`：その成分が表す片側対数振幅スペクトル [dB]（`freqs` が周波数軸）．`low` は包絡，`high` は微細構造
- `reconstruct(part)`：その成分の時間信号（元の位相を使う．「3. リフタリングと再構成」の方式．`analyze_cepstrogram` の結果）

## 4. 非機能
- 依存: NumPy のみ（テストは pytest）
- 型ヒント付き，公開 API は `cepstrum/__init__.py` に集約

## 5. 検討事項
パワーケプストラム定義の流儀，多チャネルの個別処理，先細りのリフタ，スペクトルの dB 入力，再構成のゲインの上限（谷の持ち上げすぎの抑制）．

## 6. 定義書との対応（実装）
定義書（definitions.md）は，片側の理論だけを書く．実装との対応は次のとおり．

| 定義書の量 | 実装 |
|---|---|
| スペクトル（振幅・パワー・複素，片側・両側） | `Spectrum(data, fs, n_fft, kind, sided)`．`sided="one"` は片側（I 点），`sided="two"` は両側（M 点） |
| 窓関数 | `window` 引数：`"hann"`，`"hamming"`，`"rect"`（`None`），または長さ M の配列 |
| 対数の下限 ε | `eps`（既定 1e-12） |
| ゲインの下限 δ | 内部定数 1e-12 |
| dB 基準 | `db=True` |
| 実ケプストラム，パワーケプストラム | `kind="real"`，`kind="power"` |
| リフタ | `lowpass(c)`，`highpass(c)`，`bandpass(a, b)`，`notch(q_0, W)`．境界は，秒（位置引数），`khz_inv=`（kHz⁻¹），`period_hz=`（周期）のいずれか 1 つで指定 |
| 低域成分・高域成分 | `Decomposition.low`，`Decomposition.high`．`Decomposition.log_spectrum(part)` が，自然対数基準の対数スペクトルを dB で返す |
| スペクトログラムの保持 | `store_spectrogram=True`（既定）．再構成には，`kind="real"` で，この複素スペクトログラムを保持したケプストグラムを使う |
| 入力の検査 | 無音・定数は `SilenceWarning`，クリッピングは `ClippingWarning`，不正な入力は `ValueError`．形状は `[N]` または `[ch, N]` |

- **鏡像**：`Spectrum.to_two_sided()` が，片側のスペクトルから共役対称の鏡像を補った M 点の配列を作る．両側で与えられたデータは，既にある鏡像をそのまま使う．
- **配列の長さ**：`Cepstrum.data` は，鏡像を補った対数振幅スペクトルの逆 FFT（実部）による，M 点の偶対称な配列で，前半の L 点が定義書の $\bm{z}$ である．
  `Cepstrogram.data` も M 行で，前半の L 行が $\bm{Z}$ である．リフタの重みは $\lvert q\rvert$ の関数として，この M 点全体に掛ける．
- **再構成**：保持した片側のスペクトログラムにゲインを掛け，`irfft`（片側から実信号）で各フレームを実信号に戻し，合成窓をかけて重畳加算する．
- **STFT のフレーム化**：信号の先頭に M − H 点のゼロを足してから切り出し，端まで全フレームを取る（定義書の J フレームに，端の部分フレームが加わる）．
  重畳加算は窓の 2 乗の和で正規化するので，端でも元の信号に戻る．
- **FFT 長**：`n_fft` の既定は `frame_len`（平均ケプストラムでは信号長）で，定義書の M と一致する．`n_fft` を M より大きく指定すると，窓をかけた M 点の末尾に
  ゼロを足した `n_fft` 点で DFT する（窓の長さは M のまま．周波数ビン数とケフレンシビン数は ⌊`n_fft`/2⌋ + 1 になる）．
